# Application capture / アプリケーション音声取り込み

The C++ implementation is adapted from niel's Audio-Bridge application input.
Build with Visual Studio 2022 C++ tools and a recent Windows SDK using `build.cmd`.
Place the resulting `application_capture.dll` in this directory before using application input.
The portable packages include this DLL; Python, CUDA runtimes, models and generated binaries are not committed here.

Audio-Bridgeのアプリケーション入力実装を使用しています。Visual Studio 2022のC++ツールと新しいWindows SDKで `build.cmd` を実行し、このフォルダにDLLを生成してください。配布パッケージにはDLLを同梱します。
